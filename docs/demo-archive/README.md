# Demo Project Documentation Archive

**Archived Date:** November 12, 2025

This folder contains the original PRD, epics, and stories for the **Reachy Recognizer** demo project - a simulation-based human recognition and interaction system.

## Contents

- `prd.md` - Product Requirements Document for the demo project
- `epics.md` - Epic breakdown with 4 major epics
- `stories/` - Individual user stories (38 stories total)

## Project Summary

**Original Project:** Reachy Recognizer – Human-Aware AI Companion

**Goal:** Transform Reachy Mini robot into a socially aware desk companion that recognizes people via camera, calls them by name, and reacts naturally with gestures and speech.

**Development Phases:**
- Phase 0: Simulation Mode (laptop camera + Reachy SIM)
- Phase 1: Desk Companion Mode (physical Reachy Mini)
- Phase 2: Autonomous Boom Box Mode (Pi5 + Hailo AI HAT)
- Phase 3: Mobile Companion Mode (portable/battery)
- Phase 4: Retail Vision Integration (planogram/out-of-stock CV)

## Why Archived

The project evolved from demo/simulation focus to real-world store deployment with inventory analysis and staff interaction. New documentation reflects the updated scope with privacy-first design (embeddings only, no photo storage) and quick-win features prioritized from brainstorming session.
